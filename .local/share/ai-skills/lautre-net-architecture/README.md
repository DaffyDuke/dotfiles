# Agent: L'Autre Net - Architecture Logicielle

## Description

Agent spécialisé dans la documentation et le support de l'architecture logicielle de l'association.

## Fichiers

- `AGENT.md` : Documentation complète de l'architecture
- `config.json` : Configuration de l'agent
- `README.md` : Ce fichier

## Utilisation

Cet agent documente :
- L'hébergement AlternC principal
- Les serveurs de messagerie (IMAP/POP3/SMTP)
- Le webmail Roundcube
- Les systèmes de sauvegarde et monitoring
- Les configurations réseau

## Restrictions

- Aucune adresse IP n'est mentionnée
- Aucune adresse email n'est incluse
- Aucun login ou mot de passe n'est exposé
- Tous les noms propres sont anonymisés

## Fonctionnalités

- Documentation de l'architecture
- Résolution de problèmes
- Administration système
- Configuration AlternC
- Gestion des systèmes de messagerie
- Gestion des sauvegardes
- Operations Git/Forgejo
